# 빌드랩 · StarCraft 타이밍 연구소

스타크래프트 1:1 래더를 위한 빌드 타이밍 연구용 웹 프로토타입입니다. 중앙 세로 시간축의 좌우에 내 빌드와 상대 빌드를 배치하고, 상대 목표 시각에 맞춰 대응 준비 시간을 조정합니다.

> 현재 데이터는 모두 임의 값입니다. 실제 게임의 자원·선행 조건을 검증하거나 최적 빌드를 자동 계산하지 않습니다.

- 소스 저장소: https://github.com/sleepyJK/sc1BdOptimizer
- 기존 배포는 소유자 비공개로 생성되어 공동작업자에게 열리지 않을 수 있습니다. 로컬 실행은 별도로 가능합니다.
- 상세 인수인계: [docs/HANDOFF.md](docs/HANDOFF.md)
- 작업 방식: [CONTRIBUTING.md](CONTRIBUTING.md)

## 실행

빌드와 패키지 설치가 필요 없는 정적 웹 앱입니다. Python 3이 설치된 환경에서 저장소 루트에서 실행합니다.

```bash
python3 -m http.server 8000 --directory dist
```

Windows에서는 `py -m http.server 8000 --directory dist`를 사용할 수 있습니다. 브라우저에서 http://localhost:8000 을 엽니다. 같은 호스트와 포트를 유지해야 기존 브라우저 저장 데이터를 계속 사용할 수 있습니다.

JavaScript 구문 검사는 Node.js가 있는 환경에서 실행합니다.

```bash
node --check dist/app.js
```

## 구현된 기능

- 내 빌드 / 상대 빌드의 공통 세로 시간축
- 생산 시간에 비례하는 블록 높이 및 겹치는 시간대의 자동 열 배치
- 테란·저그·프로토스의 일부 예제 항목 검색, 건물/유닛 필터, 추가
- 블록 선택, 드래그 이동, 시작 시각·소요 시간·메모 편집, 삭제
- 목표 시각 + 이동 시간과 내 대응 완료 시각 비교
- 5:30 뮤탈 예제, 확대 비율, 초기화
- 브라우저 localStorage 자동 저장 및 반응형 CSS

## 파일 구조

| 파일 | 역할 |
| --- | --- |
| `dist/index.html` | 화면 구조와 기본 문구 |
| `dist/style.css` | 다크 테마, 타임라인, 반응형 화면 |
| `dist/app.js` | 예제 데이터, 상태, 편집, 렌더링, 저장 |
| `docs/HANDOFF.md` | 현황, 내부 구조, 제한, 검증, 다음 작업 |
| `CONTRIBUTING.md` | 브랜치/PR 작업 방식과 확인 사항 |
| `.github/pull_request_template.md` | 리뷰용 PR 양식 |
| `.openai/hosting.json` | 기존 Sites 배포 식별자와 정적 디렉터리 설정 |

**`dist/`는 현재 직접 수정하는 원본입니다.** 빌드 산출물로 오해하여 삭제하거나 Git에서 제외하지 마세요. 프레임워크, npm 의존성, 서버, DB, CI는 아직 없습니다.

## 저장과 협업

연구 데이터는 각 브라우저의 `buildlab-v1` 키에 하나만 저장됩니다. GitHub는 소스 공동작업용이며, 연구 데이터의 실시간 공유나 기기 간 동기화는 구현되어 있지 않습니다. 내보내기 기능도 아직 없어 사이트 주소나 브라우저를 바꾸면 기존 연구가 자동으로 옮겨지지 않습니다.

소스와 협업 문서는 공개 저장소 `sleepyJK/sc1BdOptimizer`에서 관리합니다. 공동작업자 초대와 브랜치 보호 설정은 별도 작업이며 아직 수행하지 않았습니다. 현재 라이선스는 지정하지 않았습니다.
